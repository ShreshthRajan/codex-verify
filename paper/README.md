# Paper

- `submission.tex` — anonymous AAAI-27 AgenticSE submission (AAAI 2027 author kit).
- `preprint.tex` — the same paper with author information, for the arXiv replacement.
- `body.tex`, `appendix.tex` — shared text. Every number in the prose is a macro in
  `tables/numbers.tex`; tables in `tables/` and figures in `figures/` are generated by
  `bench/analyze.py` from the committed verifier outputs in `results/rebuild/`.
- `archive/` — earlier drafts, kept for history. Their 99-sample results are superseded;
  see Appendix A of the current paper.

Build: `latexmk -pdf submission.tex` (needs texlive with newtx fonts).
